Evidence-Grounded Scientific Agents

Trustworthy reasoning and skill reuse in evolving environments.

I am an undergraduate student in Computer Science at Qingdao University. I work on evidence-grounded agentic systems: getting agents to form conclusions that trace back to real evidence, and keeping their skills and memory reliable as tasks, code, and data change.

I build multimodal scientific agents and state-grounded collaboration systems. I care most about evidence verification, trustworthy skill reuse, and evaluation when the knowledge and models a system relies on keep changing.

I have first-author work accepted at ICANN 2026 as an Oral Presentation and published in Information.

Research Directions

Evidence-Grounded Scientific Agents

How can scientific agents generate conclusions that remain traceable to multimodal evidence?

I study agents that read scientific figures alongside their captions and surrounding text, and keep track of where each claim comes from. My current focus is tying claims to specific evidence, being honest about uncertainty, and making the analysis something a person can actually check.

Public system: PaperFigureScout

Current question: evaluation under evolving knowledge states

Trustworthy Skill and Memory Reuse

When should an agent reuse, revalidate, or discard a learned skill or memory?

I look at how an agent's saved skills and outputs depend on the context they were built in: the task, the tools it could use, the state of the code. When that context shifts, a skill that once worked can quietly turn wrong, so I study when a skill should be reused, when it should be revalidated or dropped, and how agents can check each other's work before trusting it.

Public system: Agent Plane

Published work: SkillCraft

Learning Systems under Evolving States

How should learning systems update, forget, and evaluate when their underlying state continuously changes?

I work on graph and knowledge systems that are constantly updated or asked to forget things, and I look at when reused results are still valid, what a model's internal representations really encode, and where privacy quietly leaks. A recurring question is whether a system that looks stable from the outside has actually stayed correct on the inside.

Published work: Federated Illusion

Current focus: representation-level and dependency-aware auditing

Selected Research & Systems

PaperFigureScout Code
Multimodal Scientific Agents Evidence Grounding Open Source

A research agent for the figures in scientific papers. It links each figure to its caption and the exact text that refers to it, and it will not save a conclusion unless that conclusion is tied to specific evidence it can point back to.

Agent Plane / HACP Code
Heterogeneous Agents Skill Lifecycle Open Source

A collaboration runtime that lets several coding agents, each from a different vendor, work on one shared codebase without stepping on each other. Each agent works in its own copy and submits versioned changes that reach the main branch only after freshness checks, review, and an atomic merge, and any skill it learns is re-checked before reuse.

SkillCraft Code
ICANN 2026 Oral Agent Skill Security First Author

Looks at how the same agent skill can behave very differently depending on how much the surrounding task is trusted. It builds controlled skills and multi-stage attack chains to tell genuinely malicious behavior apart from a skill that simply runs successfully in a high-trust setting.

Federated Illusion Code
Information 2026 Graph Learning First Author

Studies privacy leakage in federated graph unlearning. Even when a model's outputs make it look like a data point has been forgotten, the geometry of its internal representations can still give that point away.

Open-source Systems

CompanyAgent Code

A multi-agent framework modeled on a company org chart: it routes each task by difficulty, splits the hard ones into a DAG of subtasks, and keeps memory and feedback across runs.

Toss Code

A command-line tool for sharing the artifacts coding agents produce, with MCP support, shared workspaces, and history that follows each file.
