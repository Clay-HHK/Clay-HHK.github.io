Evidence-Grounded Scientific Agents

Trustworthy reasoning and skill reuse in evolving environments.

I am an undergraduate student in Computer Science at Qingdao University. My research focuses on evidence-grounded agentic systems: how agents form auditable conclusions from multimodal scientific evidence, and how their skills, memory, and intermediate artifacts remain valid as tasks, tools, code, data, and knowledge evolve.

I build multimodal scientific agents and state-grounded collaboration systems, with a particular focus on evidence verification, trustworthy skill reuse, and evaluation under evolving knowledge and model states.

I have first-author work accepted at ICANN 2026 as an Oral Presentation and published in Information.

ICANN 2026 Oral 2 First-Author Accepted / Published Papers Multimodal Scientific Agents · Trustworthy Skill Reuse

Research Directions

Evidence-Grounded Scientific Agents

How can scientific agents generate conclusions that remain traceable to multimodal evidence?

I study agentic workflows that jointly reason over scientific figures, captions, document context, and provenance. My current focus is on claim-level evidence grounding, reproducible context construction, uncertainty representation, and human-verifiable scientific analysis.

Public system: PaperFigureScout

Current question: evaluation under evolving knowledge states

Trustworthy Skill and Memory Reuse

When should an agent reuse, revalidate, or discard a learned skill or memory?

I investigate how executable skills and agent-generated artifacts depend on task context, tool permissions, code state, and prior execution evidence. I am particularly interested in evidence-gated skill promotion, dependency-aware invalidation, heterogeneous-agent review, and safe fallback under changing environments.

Public system: Agent Plane

Published work: SkillCraft

Learning Systems under Evolving States

How should learning systems update, forget, and evaluate when their underlying state continuously changes?

I study state consistency, dependency-aware reuse, representation-level auditing, and privacy risks in evolving graph and knowledge systems. A recurring question is whether apparent output-level stability reflects genuine internal-state correctness.

Published work: Federated Illusion

Current focus: representation-level and dependency-aware auditing

Selected Research & Systems

PaperFigureScout Code
Multimodal Scientific Agents Evidence Grounding Open Source

An evidence-grounded multimodal research agent for scientific figures. It aligns figures with captions and versioned text spans, generates structured scientific semantics, and requires claim-level evidence bindings to pass identity- and version-aware verification before persistence.

Agent Plane / HACP Code
Heterogeneous Agents Skill Lifecycle Open Source

A state-grounded collaboration plane for heterogeneous coding agents. It combines isolated workspaces, versioned proposals, dependency freshness checks, heterogeneous review, atomic merging, and evidence-gated skill invalidation and revalidation.

SkillCraft Code
ICANN 2026 Oral Agent Skill Security First Author

Audits how executable agent skills change behavior across task-trust contexts. It constructs controlled skills and multi-stage attack chains to distinguish malicious intent from successful execution under different operational contexts.

Federated Illusion Code
Information 2026 Graph Learning First Author

Studies representation-level privacy leakage in federated graph unlearning, showing that output-level confidence similarity may coexist with distinguishable geometric residuals in embedding space.
